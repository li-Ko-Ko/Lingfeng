GeneralUser GS 2.0.3

在「设置 → 音源与输入 → 音源与音色」中选择「GeneralUser GS · 通用 MIDI」。
主包提供库 0 的 128 个基础 GM 音色，保留原程序号。程序号 0 在界面显示为
「01 · 原声大钢琴」。如列表尚未更新，点击「重新扫描并保存」。

主包包含完整的上游原版 SF2、FluidSynth 运行库及原许可。独立的 GS 变体和
鼓组音色包可作为额外包安装。迁移此主包时复制完整 generaluser-gs 文件夹。

In Sound sources and instruments, choose GeneralUser GS · General MIDI.
The main pack exposes all 128 General MIDI programs from bank 0 and retains
the original program numbers. Program 0 appears as “01 · Grand Piano”.
Rescan and save to refresh the list.

The main pack contains the complete original upstream SF2, the FluidSynth
runtime and license notices. Separate GS variation and drum kits can be
installed as companion packs. Copy the full generaluser-gs folder to move
the main pack to another installation.
